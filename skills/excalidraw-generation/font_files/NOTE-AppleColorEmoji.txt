AppleColorEmoji.ttf
===================
Apple Color Emoji is PROPRIETARY to Apple Inc. and is NOT part of this repository.

On macOS, extract it locally from /System/Library/Fonts/Apple Color Emoji.ttc
(font index 0) to get emoji that match diagrams exported on a Mac:

  uv run --with fonttools python tools/build_fonts.py --apple-emoji

The file is git-ignored. When it is present, it is the primary emoji font; without
it, emoji render with NotoColorEmoji.ttf (OFL), which works on every platform.
